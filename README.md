# BioInsight

Clinical Engineering Dashboard and Biomedical Equipment Failure Knowledge Graph built using Python, Streamlit, Pandas, Plotly, NetworkX, and Matplotlib.

## Features

* Equipment Inventory Management
* Maintenance Record Tracking
* Equipment Risk Scoring
* Equipment Health Classification
* Calibration Due Alerts
* Failure Analytics
* Downtime Analytics
* Biomedical Troubleshooting Assistant
* Biomedical Failure Knowledge Graph
* Equipment Search System

## Technologies Used

* Python
* Streamlit
* Pandas
* Plotly
* NetworkX
* Matplotlib
